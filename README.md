# JAVA-POCs – Exercise Index

This repository contains practical Java exercises and utilities, useful for interviews and real-world scenarios.  
Each module is self-contained and includes its own README and example code.

## 📚 Index

- **TopWords**  
  Find the top 3 most frequent words in a list of sentences.  
  - Location: [`TopWords/`](TopWords)
  - Concepts: Streams, text normalization, word counting

- **LRUCache**  
  Implementation of a Least Recently Used (LRU) cache.  
  - Location: [`LRUCache/`](LRUCache)
  - Concepts: Collections, LinkedHashMap, cache eviction
